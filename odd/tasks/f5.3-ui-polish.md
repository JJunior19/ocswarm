# Feature: F5.3 UI polish — animations, session titles, archived agents (ocswarm)

## Objective

Three user-requested improvements, executed with PARALLEL writers (3) over
disjoint file surfaces:

- **A — Top animations**: edge particles while subagents run, spring/pulse
  polish, archived dimming. (GraphView/Gantt/theme.css)
- **B — Session title in the top bar**: the dashboard header/pills show the
  real TUI session title ("Implementar ocswarm:..."), including for sessions
  that late-joined (title sync via the TUI).
- **C — Finished subagents stay visible**: when OpenCode deletes completed
  subagent sessions, they remain in the graph as dimmed "archived" agents
  instead of vanishing.

## Shared contract (pre-implemented by the parent BEFORE writers launch)

- `archived?: boolean` on SwarmAgent (hub) and the client type mirror.
- Hub semantics for C: `session.deleted` NO LONGER removes the agent — it
  emits `agent.upsert` with `archived: true` (terminal status preserved),
  drops the session from `roots`, and evicts the oldest archived agent beyond
  a 200 cap. Client: the flag travels in the upsert (no reducer change);
  UI dims archived agents and EXCLUDES them from header totals.
- Hub API for B: `hub.setTitle(sessionID, title)` — sets title if non-empty
  and changed, emitting `agent.upsert`; materializes nothing. The server
  exposes `POST /api/title {sessionID, title}` (writer C3) and the TUI posts
  the current session's title when opening the swarm panel (deduped per
  session) — this backfills late-joined sessions' titles.

## Known limitations (documented, not defects)

- El título de sesiones previas al último reload se sincorea recién cuando
  el usuario abre /swarm en esa sesión (dedupe por sessionID en el TUI).
- Agentes archived: cap 200 (evict oldest) — suficiente para sesiones
  largas; los evicted desaparecen (agent.removed) por diseño.
- Partículas requieren edge running no-archived; con reduced-motion del OS
  se desactivan junto con springs/pulse.
